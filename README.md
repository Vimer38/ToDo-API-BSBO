# ToDo лист API — Матрица Эйзенхауэра

REST API для управления задачами с использованием **матрицы Эйзенхауэра** ( Eisenhower Matrix ).  
Проект написан на **FastAPI** и предназначен для учебных целей. Данные пока хранятся в памяти (временное хранилище), в дальнейшем планируется переход на **PostgreSQL**.

## 📖 Описание

API позволяет:

- получать список всех задач;
- фильтровать задачи по квадранту матрицы Эйзенхауэра;
- получать задачу по её `id`;
- получать статистику по задачам (по квадрантам и по статусу выполнения);
- фильтровать задачи по статусу (`completed` / `pending`);
- искать задачи по ключевому слову в названии или описании.

Проект использует **временное хранилище** — список словарей `tasks_db`, который заполнен тестовыми данными при старте приложения.

---

## 🛠 Технологии

- **Python 3.10+**
- **FastAPI** — веб-фреймворк
- **Uvicorn** — ASGI-сервер для запуска
- **Pydantic** (косвенно, через FastAPI) — валидация данных
- **datetime** — работа с датами создания задач

---

## 🚀 Установка и запуск

Установите виртуальное окружение

Установите зависимости из файла requirements.txt
pip install -r requirements.txt

В папке с файлом main.py выполните команду:
uvicorn main:app --reload
