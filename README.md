# ToDo лист API — Матрица Эйзенхауэра

REST API для управления задачами по **матрице Эйзенхауэра**.
Стек: **FastAPI**, **SQLAlchemy (async)**, **PostgreSQL (Supabase)**, **Pydantic**.

## 📖 Возможности

- CRUD для задач;
- фильтрация по квадранту и статусу (`completed` / `pending`);
- поиск по ключевому слову в названии и описании;
- статистика по квадрантам и статусам;
- **плановый дедлайн** задачи с автоматическим расчётом срочности и квадранта;
- статистика по срокам невыполненных задач.

## ⏰ Дедлайны и автоматический расчёт срочности

Вместо ручного флага `is_urgent` у задачи есть поле `deadline_at`.
Срочность считается от сегодняшней даты:

| Дней до дедлайна            | Срочность |
|-----------------------------|-----------|
| 3 и меньше (или просрочено) | Срочно    |
| Больше 3                    | Не срочно |

| Квадрант | Важность | Срочность |
|----------|----------|-----------|
| Q1       | важно    | срочно    |
| Q2       | важно    | не срочно |
| Q3       | не важно | срочно    |
| Q4       | не важно | не срочно |

Квадрант определяется при создании (`POST`) и пересчитывается при
изменении `is_important` или `deadline_at` (`PUT`).

### Создание задачи — `POST /api/v2/tasks/`

```json
{
  "title": "Сдать проект по FastAPI",
  "description": "Завершить API и документацию",
  "is_important": true,
  "deadline_at": "2026-11-27T18:00:00Z"
}
```

### Формат ответа

```json
{
  "id": 1,
  "title": "Сдать проект по FastAPI",
  "description": "Завершить API и документацию",
  "is_important": true,
  "deadline_at": "2026-11-27T18:00:00Z",
  "quadrant": "Q1",
  "completed": false,
  "created_at": "2026-11-24T10:00:00Z",
  "days_left": 3,
  "is_urgent": true
}
```

`days_left` и `is_urgent` — расчётные поля (в БД не хранятся).

## 🔗 Endpoints (префикс `/api/v2`)

| Метод  | Путь                       | Описание                                   |
|--------|----------------------------|--------------------------------------------|
| GET    | `/tasks`                   | Все задачи                                 |
| GET    | `/tasks/{task_id}`         | Задача по ID (404, если нет)               |
| GET    | `/tasks/quadrant/{q}`      | Задачи квадранта Q1–Q4                     |
| GET    | `/tasks/status/{status}`   | `completed` или `pending`                  |
| GET    | `/tasks/search?q=...`      | Поиск по title/description (от 2 символов) |
| POST   | `/tasks/`                  | Создать задачу                             |
| PUT    | `/tasks/{task_id}`         | Обновить задачу                            |
| PATCH  | `/tasks/{task_id}/complete`| Отметить выполненной                       |
| DELETE | `/tasks/{task_id}`         | Удалить задачу                             |
| GET    | `/stats/`                  | Статистика по квадрантам и статусам        |
| GET    | `/stats/deadlines`         | Сроки невыполненных задач                  |

### `GET /stats/deadlines`

Возвращает задачи со статусом `pending`: название, описание, дата начала
(`created_at`), дедлайн и оставшийся срок `days_left` в днях.
Сортировка по возрастанию `days_left`.

## 🚀 Установка и запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте `.env` с `DATABASE_URL` (строка подключения к Supabase).
4. Запустите: `uvicorn main:app --reload`
5. Документация: http://127.0.0.1:8000/docs
